# 動画カット編集

大容量動画をローカルでカット編集し、複数ファイルを指定順に連結してMP4に書き出すWebアプリです。動画ファイルは外部サービスへ送信されません。

## 起動方法

1. Node.js 18以降とFFmpeg（`ffmpeg` / `ffprobe` の両方）をインストールし、PATHから実行できるようにします。

### ワンクリック起動

- Windowsでは [start.bat](./start.bat) をダブルクリックするとサーバーが起動し、ブラウザーが開きます。
- VS Codeでは「ターミナル」→「タスクの実行」→「動画編集アプリを開く」を選択します。

### 起動コマンド

```powershell
npm.cmd start
```

起動後はブラウザーで開いてください。

## アプリを開く

[http://127.0.0.1:4173](http://127.0.0.1:4173)

## 使い方

1. 「動画ファイルを追加」で複数の動画を選択します。後から追加した動画は連結リストの末尾に加わります。
2. 連結リストの上下ボタンで順番を調整し、不要な動画を削除します。
3. 動画を選択してプレビューし、開始・終了位置で「現在位置」を押すか秒数を入力して使用区間を設定します。複数区間を設定した場合は時間順につながります。
4. 各動画ごとに出力する音声トラックを選びます。複数選択時はステレオにミックスダウンし、音声トラックがない動画は無音で連結します。
5. 「動画を書き出す」を押します。出力はH.264 / AACのMP4です。解像度は連結リストの先頭の動画に合わせます。

プレビューでは、選択中の音声トラックをブラウザー互換のMP3へオンデマンド変換し、映像の再生・停止・シークに同期します。元動画の音声を直接再生する代わりに、選択中のトラックがMP3として生成されます。
各音声トラックは個別のMP3として生成され、プレビュー画面で映像と同時に再生・停止・シークされます。トラックごとの再生コントロールから個別に操作できます。

素材と出力はアプリ用の一時フォルダーに保存されます。大きな動画の読み込み・変換には、動画サイズに応じたディスク空き容量と処理時間が必要です。
起動時に利用可能なドライブの空き容量を比較し、空き容量が最も大きいドライブ配下の `video-cut-editor-temp` を一時保存先として自動選択します。環境変数 `TEMP_DIR` を指定した場合は、その保存先を優先します。
連結リストから動画を削除すると、元ファイルと生成済みのプレビューMP3を含む関連する一時ファイルを削除します。書き出し中は推定残り時間をバーの下に表示します。使用区間は時・分・秒で設定・表示します。

## GitHub Pages / サーバー環境

GitHub Pagesは静的ファイルの配信だけで、FFmpegや動画アップロードAPIを実行できません。リポジトリをGitHub Pagesへ公開した場合でも、実際の編集にはNode.jsサーバーを起動してブラウザーで開く必要があります。

`Dockerfile`を使うと、Node.jsとFFmpegを含むサーバー版をコンテナで起動できます。

```bash
docker build -t video-cut-editor .
docker run --rm -p 4173:4173 video-cut-editor
```

`.github/workflows/deploy-pages.yml`はブラウザー画面だけをGitHub Pagesへ配置する設定です。静的画面では動画処理APIを利用できないため、ローカルまたはコンテナサーバーを併用してください。
